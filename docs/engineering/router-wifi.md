# 同路由器连接（STA）

2026-10-11：已接入普通浏览／下载的 STA 启动源码及工作台入口。未编译、运行、测试或打包；不能据此宣称任何相机型号已兼容。

## 使用范围

手机先通过系统设置连接路由器；相机也需要事先保存该网络及密码。用户读取蓝牙相机资料后，可输入路由器名称并点击“让相机连接此路由器”。应用只发送名称，不读取、保存或配置路由器密码，不更改手机的系统 Wi-Fi 配置。界面说明这是浏览／下载入口，拍后发送与选定发送继续使用原有直连入口。

当前需要系统提供恰好一个 Wi-Fi Network；多个网络时不静默选择，提示改用手动连接／查找入口。Network 在启动前固定下来，发现和相机 HTTP 都绑定该 Network；蜂窝网络、默认网络切换及另一个 Wi-Fi 不作为自动后备。注册断线观察并在注册后再次检查网络，取消或失败只释放应用自己的监听，不断开系统已有的路由器连接。

输入的名称由用户核对，并非从 Android 读取的 SSID。为避免为名称读取增加定位权限，本轮未接入系统 SSID 读取，也不声称已证明输入名称与当前 Network 相同。错误名称、相机未保存密码、路由器设备隔离仍可能导致失败。名称仅保存在当前界面／连接操作内存，不写 Room、DataStore 或日志。

## 恢复的协议依据

依据只读官方 LUMIX Sync 2.0.15 APK 的 JADX 输出，原始 APK 和恢复源码未修改。

| 环节 | 恢复位置 |
|---|---|
| 路由器名称写入 Wi-Fi 服务 `5ae57260-3214-11e6-979e-0002a5d5c51b` 的 `18345be0-3217-11e6-b56c-0002a5d5c51b` | `p033E4/C0393g.java:m1791q1`，写入类型 12 |
| SSID 去外层引号后补 NUL 至 32 个字符，再 getBytes | `p321v4/C5119d.java:m27962a`、`p068J4/C0941p.java:m4403x` |
| 名称写入后等待选择通知；`18345be1...` 首字节 0 为 STA，其余为 SoftAP | `C0393g.java:465–530`、其内部 `e.a.run` |
| STA 向 `0d6f1880...` 写固定 2 | 同通知处理与 `p026D4/C0272a.java:f1074i` |
| 类型写入成功后普通连接向 `e182ec40...` 写固定 3 | `C0393g.java:1005–1013`、`C0272a.f1069d` |

先按原有旧／APS 分支建立应用自己的身份，暂时读取的相机直连密码立即释放。检查名称写入、类型写入、模式写入及两种连接通知能力；缺少任何一项就提示手动入口。名称限制为 1–32 位可打印 ASCII，保持空格及大小写，固定输出 32 字节 NUL 补齐。参考编码器按字符数补齐，多字节名称存在长度差异；本轮没有猜测中文名称的正确格式，手动在相机上连接后查找仍可使用。

固定名称载荷长于默认 ATT 单次写入容量，因此先请求 MTU 64，等待 `onMtuChanged` 成功且实际 MTU 至少 35，随后才订阅与写入。实际 MTU 以回调为准；[Android BluetoothGatt 文档](https://developer.android.com/reference/android/bluetooth/BluetoothGatt#requestMtu(int)) 说明 Android 14 起首个客户端会请求 517，不可把请求值当作实际协商值。此处不要求恰好 64，不截断名称。

订阅完成后开启本次名称回复等待，写名称并等待 GATT 成功回调及 STA 通知，两者缺一不可；20 秒未确认或选择 SoftAP 即结束，不自动切换直连。随后顺序写类型 2、普通模式 3，分别等待 GATT 回调。连接拒绝、空状态、取消、蓝牙断开结束 STA 交接。

GATT 的写成功及 STA 选择只说明协议步骤完成。继续在固定 Network 上发现相机，整体等待至多 45 秒；未找到时提示核对名称、相机密码及路由器互访。多个相机必须由用户选择；只将普通 BROWSING 作为预期 HTTP 模式，握手检查发生在目录初始化之前，不接受意外发送模式。BLE 地址与发现的 HTTP UDN 之间没有恢复出的密码学绑定，不把单个发现结果称作已证明是同一台相机。

## 尚需继续

- STA 的拍后发送／选定发送、模式切换重新握手、连接资料通知、扩展事件、BLE 与 HTTP 身份对应。
- 多字节 SSID、多个 Wi-Fi Network 的明确选择、低 MTU 设备的完整写入方式、逐型号系统绑定和固件差异。
- AP 隔离／组播被禁用时的相机地址资料读取。现有 SSDP 发现仍有直接网关后备；普通路由器网关不是相机，不能把该后备当作 STA 发现保障。
- 用户明确要求后才进行编译、实际设备连接与相关测试，按实际结果更新逐型号表。
