## 仓库简介

松下相机传图、胶片模拟与双 LUT，最后给照片加一张画框。一个仍在开发的 Android 摄影工具。

## 发布页正文

这是松映的开发预览。它想把相机传图、选胶片风格、套 LUT 和画框导出放在一起，少在几个应用之间来回切换。

目前支持松下相机连接与媒体浏览、批量传图、胶片模拟、两款 LUT 叠加和画框导出。批量照片可以逐张调整，也可以沿用第一张的参数。RAW 暂时只取文件里的 JPEG 预览，不做 RAW 显影。

新源码中的智能推荐能发现还没下载的官方 LUT：先看目录和创作者小图，喜欢再下载。它会注明哪些是实际试套，哪些只是例图的色彩匹配。照片不会上传。

最低要求 Android 11。相机兼容、连接稳定性和大图耗时还需要更多真实设备反馈。遇到连接问题，请附上应用里导出的连接日志、相机型号、手机型号与系统版本；反馈颜色或光晕时，最好同时说明胶卷、曝光和开关设置。

这不是松下官方应用，也没有遥控拍摄功能。欢迎把遇到的具体问题留下来，尤其是能重复出现的操作步骤。
