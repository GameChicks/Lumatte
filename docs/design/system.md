# 设计系统基础令牌

2026-10-12 完整页面、交互、动态与状态规范见 [完整设计规范](specification.md)。以下为基础色彩与间距令牌。

以照片为视觉主体，材质表现用于承载区域、暗盒、画框和控件。照片预览不叠加界面纹理或改变对比度。

| 次级文字 | #68685F | #B3B8AC |

默认跟随系统；不使用动态壁纸取色覆盖摄影工作台的固定色彩。材质使用低强度渐变、细边和小阴影；主导航底部约 144 dp 单独采用渐进模糊，照片与其他界面保持清晰。

屏幕边距 20 dp，面板内距 16–24 dp，常规间隔 12 dp，紧凑间隔 8 dp，触摸区域至少 48 dp，卡片圆角 24–30 dp。正文使用 OPPO Sans，NHL Minnesota 用于欢迎字、波点用于短标题、Playfair 与 Dancing Script 用于艺术层级，参数保持可读。

系统状态栏、导航栏与主题一致。全屏照片和暗盒页面的返回按钮及主操作位于安全区，滑动内容可以延伸到屏幕边缘。颜色、亮度和马达反馈不能成为唯一选中提示；提供名称、序号和可访问性描述。

源码在 `core/design/` 和 `app/Mirror*.kt`；具体编译和设备证据以 [实现记录](implementation.md) 为准。
