# 水印细节分组与暗盒连续姿态 · 0.1.5

用户目标仍是对照原始参考逐项完善，当前优先级为水印 → Film → 收藏质感。此记录只描述本轮可核对的推进，完整目标继续有效。

## 水印

沿用 0.1.4 的紧凑预览、三列实际画框小样、固定衬线标题与三个分区。这轮将细节从连续长表单改为签名与拍摄信息、构图与纸边、当前预设配色、暗盒标签和折叠更多文字几个纸面组。比例、字体、方向和色彩自动换行，字体按钮使用成片同一批 bundled 字体，避免七个名称全用 OPPO 正文而无法判断字形。没有加入新字体或重复字体资源。

核对 FrameRenderer 的生效范围后，仅 PALETTE / FILM 展示取色与固定色，装饰图仅 PALETTE 展示；不改旧 renderer，不清除切换后的原配置。原 showPhotoMetadata 实际同时影响标题 / 副标题 / 页脚，名称改为“显示标题与拍摄信息”；关闭后，额外输入和字体操作禁用并提示，签名独立保留。暗盒标签直接成组，不再藏在额外文字里。

输出、曝光、LUT 强度、颗粒与纸边改用项目滑杆：48 dp 触控高、3 dp 轨道、9 dp 手柄及拖动光晕，水平阈值后才接管手势；竖向仍可滚动。整数尺寸 / 质量按 100 个档位量化，原范围和初值 100% / 95 保持。提供语义和方向键入口，但 TalkBack / 外接键盘尚未运行确认。保存位置采用同一纸面分组与项目选项。

合成位图预览不编码 JPEG，这轮将预览 options 的 jpeg.compressionQuality 归一为 100，并从效果依赖中移除单独质量变化；缩略图采用相同归一。实际输出快照仍使用用户设置，尺寸仍影响像素、画框仍扩展画布。此处源码证明消除了质量对同像素缓存 key 的影响，没有以截图宣称已测得节省多少算力。

## Film

暗盒姿态跟随场景从分类 12° → 轮播 −66° → 详情 0° 连续插值，返回反向，进 / 出两端均 420 ms。未关联的类别保持原姿态。尝试使用共享边界时，实际录屏发现暗盒双轮廓和浅色裁切框；改为同图像 sharedElement 后，再次录屏逐帧查看，中心对象保持单一，返回连续转向。文字继续共享边界。

依据 [Android 共享元素文档](https://developer.android.com/develop/ui/compose/animation/shared-elements)，相同视觉对象使用 sharedElement，视觉不同的内容可以使用 sharedBounds。最终判断以本项目录屏为准，并非仅照文档替换就认定完成。

pager 小数偏移在绘制 / graphicsLayer 中读取，文字只在中心阈值变化时更新；邻卷 BlurEffect 按密度缓存八档。没有运行帧率 / 基准套件，不能把这次改动等同于性能验证。保留停稳 500 ms、入场 1000 ms、返回不重新开启详情和邻卷先吸附的逻辑。完整目录材质、快速打断和各分类间移动仍需继续查看。
