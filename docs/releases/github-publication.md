## README 首页介绍

松映 · Lumatte 是一款开源 Android 摄影工具，把松下相机照片传输、移动胶片风格、LUT 试套和画框导出放进同一条本地工作流。最低 Android 11；这是独立第三方项目，与松下没有隶属关系。

## Release · 1.0.0

**标题：** `Lumatte 1.0.0`
