LUT 使用 [Compose 官方共享元素机制](https://developer.android.com/develop/ui/compose/animation/shared-elements)，不同位置的同款 LUT 使用不同的卡片实例 key。Film 使用共享边界、pager 与距离驱动材质。模糊使用 GraphicsLayer 记录和带蒙版的局部绘制，参考 [Compose 图形修饰符](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)。源码设计不构成动画连续、光学对齐或帧率已验证。
