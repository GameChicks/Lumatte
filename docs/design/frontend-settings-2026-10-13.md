## 本轮实现

- 新增 Instrument Serif 真实窄衬线斜体；保留 Cormorant 与 Great Vibes。字体来源 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/instrumentserif)，OFL 随资源保存。收藏叠排按实际字形边界定位，交叉处以独立合成层挖出细小间隔，使后方渐变透出；不将两个字面直接糊在一起。胶卷分类展开标题也使用窄斜体。
- 编辑与画框预览使用水平 pager，可左右滑动或点击上一张 / 下一张。放大阅览同样支持，切换同步所选照片、配方、序号和照片条。每一页渲染自己的配方，滑动结束才变更全局选择；任务执行时禁用切换。
- 水印增加机型、镜头、焦距、光圈、快门、ISO、拍摄时间独立开关。整批共享开关，每张图按实际元数据过滤空值；不再用文件名冒充相机。保留用户自定义文字和现有画框配置，预览与正式输出共用同一逻辑。
- 新增从连接页进入的完整设置页：跟随系统 / 浅色 / 深色、减弱动画、触感反馈、胶卷自动展开、显影动画、JPEG 尺寸 / 质量、任务与缓存、关于与离线许可、支付宝 / 微信捐赠。全部页面和系统栏使用生效主题；外观不会仅改变设置页。用户偏好在原个人配置中新增键，保留相机、收藏与记录。
- 两张收款图原字节复制到 drawable-nodpi，原件保持在 Downloads。放大查看并可通过 MediaStore 保存原字节；失败时仅移除该次未发布副本，不重绘二维码。未运行扫码或支付验证。
- LUT 颗粒可独立关闭并保留强度，Bayer 4×4 抖动可单独启闭。Kotlin / 原生 CPU 同步接线、缓存配方与导出快照都包含开关；默认抖动关闭，旧配方保持原效果。参考过程见 `research/lut2photo/README.md`。
- `.cube / .vlt` 多选导入，VLT 严格检查 4913 组整数与 17 点尺寸。缓存版本 2 记录非均匀 VLT 输入格，仍读取旧版本 1；不改写源文件。Room 9→10 仅新增两个布尔列，旧颗粒保持开启、旧抖动关闭；新增画框开关按缺省值兼容旧 JSON。
- 进度栏移入页面上方独立布局空间。展开 / 收起都有自己的行，不再覆盖右上导入、关闭或其他按钮；传输和导出同时存在时分别提供暂停入口。
