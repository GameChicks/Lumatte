# 1.0.0 / 18 · 2026-10-18

松映 · Lumatte 1.0.0 是首个公开版本。本次修正胶片暗盒的胶片衔接、片尾和对应胶卷外观，移除透明票根描边，并让这两款画框在新选用时默认 PNG。应用代码采用 GPLv3；第三方内容仍按各自许可处理。

- 胶片的上下齿孔带从暗盒正文范围接出，片尾使用弯曲收窄及非直线裁口；PNG 的齿孔、片外留白为透明。
- 未使用胶片模拟时，通用暗盒保留 Lumix Film Mirror 文案，使用 Julius Sans One；使用胶片模拟时，共用对应暗盒原图，不重新贴通用标签。选用品牌暗盒时不将它压成自定义 120 形状。
- PNG 记忆票根保留纸面、齿边和打孔，取消灰色外沿与孔洞描边。
- 新选用「胶片暗盒」「记忆票根」时，尺寸和 JPEG 质量数值保持原样，只将格式默认切换到 PNG。用户仍可在输出区主动改回 JPEG。
- 公开源码同步修复两款“千禧回声 cold / warm”文件名的编码错误，LUT 字节与本机原始文件相同；不改变已构建 APK。发布仅同步当前源码树，不推送本机旧历史。
