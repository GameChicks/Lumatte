# 应用内连接日志

2026-10-15。用户需要在真实 S5 连接失败时直接获取可回传的数据。此前 `LFMBle` / `LFMWifi` / `LFMCamera` 只写开发者 Logcat，本次增加应用自己的本地日志文件和连接页面入口，不需要电脑抓取或新增系统日志权限。

## 手机端使用

连接页面上方有“连接日志”区域，普通 Wi-Fi、蓝牙和已连接页面共用入口：

1. 默认开启自动记录，用户可随时暂停；开关会保留到下次启动。
2. 连接失败后点“查看日志”，选择本次或历史记录。窗口显示所选文件末尾，保留时间戳与错误上下文，可选择文本。
3. 点“导出最新日志”，或在查看窗口点“导出所选日志”，通过安卓系统文件选择器保存 `.log`，然后由用户自行发送文件。
4. “清除”只删除本功能的日志。自动记录开启时，后续事件会创建新文件，不影响相机配对、照片、队列或用户设置。

日志操作不依赖相机连接的 busy 状态，所以连接等待、失败或取消后仍可查看和导出。导出完成后才显示成功，文件选择取消不修改原记录。系统文件选择器使用 `text/plain` MIME 和 `.log` 文件名；没有自动上传或发送给他人。

## 保存与保留

实现为 `core:camera/CameraConnectionLog`，进程内只有一个串行写入器；协议回调投递事件，文件 I/O 在独立线程完成。路径是应用私有 `noBackupFilesDir/connection-logs/`，文件名形如 `ConnectLog-20261015_123456_123.log`。不是缓存目录，正常进程终止或应用重启后保留历史；卸载/清除应用数据仍会删除。每行写入后关闭文件，已经完成的写入可用于排查中断，但不宣称具有断电 fsync 保证。

单份最大 256 KiB，最多 8 份，达到容量时创建新文件并淘汰最旧记录。整个进程的多次相机操作可进入同一份文件；暂停再开启或下次启动后产生新的记录。历史选择器可读取上一进程的文件，避免只导出本次重启后的空白上下文。

文件导出先在串行队列取得不可变字节快照，再写入用户选择的文档；并发日志写入不会改变这份快照。轮换已淘汰/用户已清除的文件会给出保存失败提示，不从其他目录猜测替代文件。存储错误会暂停内存中的文件记录并显示原因，不使相机操作失败；用户可重新开启尝试。

## 记录内容

| 阶段 | 诊断数据 |
| --- | --- |
| 头部 | 应用版本/版本号、手机品牌/型号、Android 版本/API、日志格式版本、连接流程版本 |
| 时间 | 带 UTC 偏移的事件时间、相对单调时钟毫秒 |
| 蓝牙扫描 | 所需权限是否完整、缺失权限类型、定位开关状态、蓝牙开关、收到广播/松下广播/候选数量、广播状态数字、扫描错误码 |
| GATT | 操作种类、公开协议特征 UUID、提交状态/回调状态/超时、旧身份或 APS 分支、已识别通知的首字节状态 |
| 网络启动 | 初次模式 5 或普通模式 3、SoftAP 类型、网络安全类型、系统等待限额、实际等待耗时、就绪/不可用/丢失 |
| HTTP | GET/POST 的状态码、授权尝试次数、legacy/challenge 分支、标识表示方式、已识别的授权状态词 |
| 配对/相册 | registration 与 media-connect 阶段、配对授权检查点、播放模式准备、收到的目录页项目数和偏移 |
| 中断 | 用户取消/断开、前后台变化、错误类型与失败阶段、已识别协议错误码 |

成功事件仍区分“请求已被 Android 接受”“GATT 回调成功”“HTTP 已授权”和“照片目录可用”，不把其中某一项当作完整连接成功。错误日志没有直接写异常原文或堆栈，以免系统异常包含带凭据的 URL 或文件名；对应请求的数字状态码和失败阶段单独保留。

## 隐私范围

只接收本应用显式调用的连接事件，不读取 Logcat、蓝牙抓包或其他应用文件。没有记录密码、SSID、手机/相机 MAC、应用客户端 UUID 值、challenge 内容、会话 ID、原始 HTTP/蓝牙负载、照片名或照片内容。公开协议的固定特征 UUID 是操作类别，不是手机/相机身份，保留供对照官方和第三方的操作顺序。

记录入口另外清理控制字符、URL、敏感键值、MAC、IPv4、非协议 UUID 和长十六进制标识。该清理是对受控事件的补充，不能据此允许后续调用方传入任意原始包或异常原文。当前通知只记录四种已识别连接/发送特征的状态值；身份和密码特征不会被转储。
