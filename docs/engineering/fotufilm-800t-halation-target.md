# Fotufilm 800T：Halation 的观感目标与源码差异

2026-10-14 用户明确：选择 Fotufilm 并非主要因为速度或理论，而是其 Cinestill 800T 的 Halation 表现符合用户对胶片光晕的认知。该效果成为空间光晕的视觉参考目标。柔光仍为独立效果，保留关闭、1/8、1/4、1/2；曝光仍只有一个控件。

初稿只核对源码；随后用户提供了火焰 Halation 开关对比和标注为真实 CineStill 800T 夜景的两张图片。观察目标与本轮实际修改见 [移动空间效果 v2](optical-spatial-v2.md)。没有运行渲染、图像对比、设备测试或基准，不把源码特征当作已经复现的视觉结果。用户所指引擎的具体版本、输出模式、格式与调节值仍未确认，暂以固定提交的默认选项作为研究起点。

## 固定参考与新发现

参考提交为 `065590107a34875728adbfd61fc1f85316d7c353`：

- [Pipeline.swift](https://github.com/DhaliwalX/fotufilm-engine/blob/065590107a34875728adbfd61fc1f85316d7c353/Sources/FotufilmCore/Pipeline.swift)：默认 `halationScale=1`、`halationReturnRatio=nil`、`halationSourceColour=0`、`halationModel=legacy`。默认保持胶卷的返光通道比例，不随意把弱通道抬高到最强通道。源码还包含独立的 Layered Transport；不能混称为同一种实现，也不能假定用户看到的就是其中一种。
- [cinestill800t.json](https://github.com/DhaliwalX/fotufilm-engine/blob/065590107a34875728adbfd61fc1f85316d7c353/Sources/FotufilmCore/Stocks/cinestill800t.json)：Legacy 返回比例为红记录 0.03、绿记录 0.00101248、蓝记录 0.00000094，红记录明显占主导；另有返回矩阵、空间 profile 与 layered construction。此处的“记录”是胶片曝光域，不是把最终 RGB 图染红。
- [FilmEngine.swift](https://github.com/DhaliwalX/fotufilm-engine/blob/065590107a34875728adbfd61fc1f85316d7c353/Sources/FotufilmCore/FilmEngine.swift)：强度、返回谱、源色混合、空间核分开处理；提高 source colour 会抬升弱通道，改变光晕颜色，而非单纯提高强度。
- [Halation.swift](https://github.com/DhaliwalX/fotufilm-engine/blob/065590107a34875728adbfd61fc1f85316d7c353/Sources/FotufilmCore/Halation.swift)：三个共享的中心高斯尺度、每记录独立权重，拟合连续边缘响应；返光份额使用 `s/(1+s)`，强度与形状分离。
- [Halation.h](https://github.com/DhaliwalX/fotufilm-engine/blob/065590107a34875728adbfd61fc1f85316d7c353/Sources/FotufilmHalide/Stages/Halation.h)：散射混合减直接项，再通过返回矩阵进入接收记录。均匀场的空间修正为零；宽高斯可采用逐尺度降采样，并修正离散 sigma。

最终光晕颜色、宽度和亮部过渡还受到感光、显影、印相/扫描与输入曝光影响。不能只拷贝这三个比例，就保证得到用户认可的 800T 成片。

## 修改前移动实现的具体差异

以下表格记录修改前基线 `d9d955c` 的问题与研究方向。v2 已移除固定亮部阈值、RGB 强度下限和空心光晕，采用三尺度归一化混合；为减少手机开销，分析顺序改为线性面积平均后在小网格查响应表，不能再把下面的“源像素先提取再降采样”当作当前行为。

| 当前源码 | 对参考观感的影响或限制 | 后续处理方向 |
| --- | --- | --- |
| 亮部掩码阈值 `max(0.06, peak*0.55)`，在线性 RGB 域计算 | 若整张夜景的线性峰值不足 0.06，所有源像素都不能成为光晕发射源；此时再增大输出强度也无效。这是源码可推导的条件，不是已确认的用户照片根因 | 研究相对亮部/响应域提取，避免固定绝对阈值把低曝光灯点全部剔除；同时保留暗部噪声抑制 |
| RGB 强度分别设置 0.10 / 0.025 / 0.003 下限 | 即便胶卷蓝记录原始返光为零，也会生成蓝通道散射；强度下限改变通道比例，可能趋向更白的光晕 | 可辨识强度应作为整体倍数，保持空间 profile 的通道比例；不独立给所有通道加最低强度 |
| 两尺度宽场减去模糊核心，仅保留正值 | 是亮部周围的艺术叠加，与参考的直接光/散射光再分配不同；负的核心修正被丢弃 | 评估三尺度中心核与带符号的响应域修正。CPU/GLES 已在加空间场后夹取非负响应，可承载带符号场，但仍需明确模型语义 |
| 每通道 sigma 最少 1.2 个分析像素 | 三个小的物理半径都可能落入同一下限，分辨率变化与近场形态被简化 | 区分近场与宽尾网格，保存参考半径；不要用统一大半径制造“更强”的光晕 |
| 长边固定不超过 512 的空间场 | 所有原像素先提取再面积平均，保留小灯能量；但场本身仍会丢失灯点的细小边缘 | 保留现有提取顺序，研究近场局部细化与宽尾多分辨率计算，整图 JPEG 输出仍为 100% |

补充核对：本项目离线胶片表生成器明确关闭空间项和随机颗粒，manifest 为 `spatialEffectsBaked=false`。因此无需再次计算桌面完整光谱流程，但引入 Fotufilm 的平场归一化公式时必须说明它是否假定均匀返光已包含在特性曲线内。不同引擎的表不能直接混用这一假定。

## 移动适配的落点

首先完成可版本化的空间 profile：近场/主场/宽尾半径、各记录的三尺度权重、返回比例及矩阵、平场归一化约定、输入/输出域与来源信息。参数离线生成并内置，不向普通用户开放一排专业设置。

保留“Halation 开/关”操作，但开关的目标是明确可见的胶片返光形态，不是整体偏红、全局提亮或同时开启黑柔。夜景有可用灯点时重点核对边缘的红暖散射、平滑扩散与亮部核心过渡；纯暗图或没有可用高光的输入不强行产生效果。具体观感以用户认可的参考输出为准，不能凭源码注释宣称已经一致。

初版空间实验与颜色模型分开记录，不能在当前 Vision3 500T 模型上替换光晕后就将整款预设命名为已准确复刻 Cinestill 800T。现有目录尚无该型号；真实新增预设仍需响应/显影/扫描模型与资料校准。

手机继续采用离线胶片表、GLES3/原生 CPU 与有界空间场。目标仍是骁龙 865、2400 万像素、Halation 开、黑柔关、带画框的完整导出少于 15 秒；该目标尚无优化版实测结果。不为追求参考光晕而静默降低导出尺寸。
