## 会话与队列

- 浏览会话在 HTTP 授权后、准备相册前启动独立保活。保活与缩略图、SOAP、流式下载共用当前选定相机 Network，但不等待下载持有的命令锁。注册阶段不启动；主动发送沿用已有接收器，避免重复保活。
- 成功响应后间隔一秒；单次超时 5 秒，暂时 busy 允许继续。401 / 403 等授权拒绝立即使会话失效；其他保活错误连续三次后失效。
- 缩略图、目录和普通传输的授权失败都会进入显式断线状态。关闭旧会话、停止保活并暂停队列，保留已完成文件、选择和任务；由用户点击重连，在既有恢复路径里重读媒体资源并验证身份。没有自动重放授权、没有无限重试。
- 普通批量传输遇到会话拒绝，当前和剩余任务暂停，避免逐项标记失败。文件与存储契约没有改变。
- 后台空闲宽限延长为 30 秒；返回会取消释放。活动传输仍由前台服务持有。超时主动释放有日志和界面说明。
- 日志新增保活开始、首个成功/每 30 次成功、失败和失效事件，以及缩略图 HTTP 错误码；不记录 URL、照片名、网络名或身份数据。

## 交互检查与修改

| 问题 | 修改 |
| --- | --- |
| 卡片底部状态/浏览按钮裁切 | 提高卡片最小高度，按系统字体放大补偿；状态内容分配明确空间，AnimatedContent 填满卡片 |
| 上下滑动状态硬切、背景立即换色 | 内容跟随拖动，释放后滑动/淡入淡出与回弹，背景渐变插值；减少动态效果仍受原设置控制 |
| 已有相机卡片整张点按无响应 | 正常状态整张可点，打开对应相机的连接/相册页；新增与删除按钮保留各自动作 |
| 手机相册入口实际跳连接页 | 明确标为“手机相册”，打开本地照片导入，成功后进入查看/编辑；相机卡片仍打开相机媒体 |
| 单列缩略图，滚动效率低 | 自适应网格，普通手机宽度约三列，整格多选、选中态、RAW/视频标记，只加载可见缩略图 |
| 最新照片要翻到最后 | 浏览从相机自然追加目录的尾部倒序分页，不只是将最旧的首屏倒排；校验总数与 UpdateID，列表变化时提示刷新 |
| 按钮跟随长列表消失 | 固定底部“传入选中”按钮，显示选中数量；增加选择已载入/取消选择 |
| 重复点击加载与滚动混乱 | 接近已载入末尾自动加载更早照片；保留手动入口，错误后停止自动重试；不再将固定高度单列塞入相机页外层滚动列表 |
| 日志与长篇说明排在照片/主要动作之前 | 连接帮助和日志可展开，默认展示主要操作；错误与重连始终在相册顶部可见 |
| 已连接后加载更多仍展示首次连接步骤 | 仅连接过程中展示连接步骤；已连接的读目录操作使用读取提示和“取消操作” |
| 小屏宽度不足的多按钮行 | 日志和 Wi-Fi 安全类型/操作改为可换行布局 |

发送队列的读取/确认顺序保持原样，不套用倒序浏览；没有增加遥控功能。最新优先依赖 Panasonic 目录自然追加顺序（本次 S5 日志/画面显示为从旧到新）。没有读取全部文件进行手机排序，也没有新增后台缩略图抓取。
