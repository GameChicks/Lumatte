# Lumix Film Mirror · 完整设计规范

版本：2026-10-13。最新要求以用户本轮文字为准。图片中的旧按钮、旧会话和 APK 为参考证据；不把“应用到相机”、三栏底栏或旧字体当成当前功能指令。实现与验证状态见 实现记录。

## 1. 统一设计语言

一间轻盈的数字暗房：连接页以冷蓝弥散和圆点体现相机身份；Film 以纸面、衬线和真实暗盒展示胶卷；LUT 以彩色拍立得展示创作者作品；水印回到安静的照片构图。共用中性背景、对齐网格、几何线形图标、轻量材质和一致的动态节奏。

正文采用 OPPO Sans，点阵仅在连接首页用于短标题、型号和引号；衬线用于胶卷叙事，手写用于 LUT 名称。混排不超过这四种角色。照片本身不叠加 UI 噪点、高光或纹理。简洁几何控制操作区域，复古材质只放在卡片、纸边和暗盒。

## 2. 导航与工作流

| 主入口 | 默认内容 | 后续流程 |
|---|---|---|
| 连接 | 相机、连接、相册、用量、创作记录 | 多选 → 仅导入手机 / Film / LUT |
| Film | 负片 / 电影卷 / 反转片 / 黑白卷 | 导入 → 选型 → 参数预览 → 显影 → 反转呈现 → 画框与导出 |
| LUT | 今日推荐 / 分类 / 搜索 / 收藏 / 添加 | 导入 → 选择两个 LUT → 强度、顺序与颗粒预览 → 画框与导出 |
| 水印 | 画框与构图 | 导入原图 → 选择画框和文字 → 导出 |

默认进入连接；底栏固定为连接、Film、LUT、水印。相机与网络页面不改写照片配方。主入口导入创建新批次；编辑和导出页的继续导入追加到当前批次。已有批次从管理页选择。

空照片时仍可浏览胶卷、官方目录和收藏。确认某胶卷或 LUT 时引导多选导入，保留对象与目标槽直到导入结束。取消文件选择器或导入失败不套用到上一批，不自动保存。选择来源与效果配方分离。

详情返回到同一分类 / 原滚动位置；画框返回参数预览；显影返回参数预览；相机管理返回连接页。返回与隐藏进度不等于取消任务。

## 4. 字体、字号与混排

| 角色 | 字体 | 使用边界 |
|---|---|---|
| 正文 / 参数 / 状态 / 按钮 | 官方 OPPO Sans 4.0 可变字体 | 连续文本和所有精确读数，使用运行时字重 |
| WELCOME | Teko Bold 700 | 首页大字，一行，按可见字形边界做左高右低透视，下缘与相机卡叠放 |
| 型号 / 短标题 / 引号 | 金字社统圆体的 Pineframe Tongyuan UI 子集 | 不用于介绍正文；新增字符时更新 OFL 子集 |
| 英文艺术标题 | Playfair Display | Film / LUT 和胶卷叙事层级 |
| 中文艺术标题 | 思源宋体 Heavy，本机副本 | 水印、分类、详情大标题；不覆盖正文读数 |
| LUT 名称 | Dancing Script（英文） / 栗壳坚坚体（中文） | 拍立得下缘与详情名称 |

正文 14–16 sp；辅助 11–12 sp；一般标题 23–30 sp；详情主标题 60–74 sp；Film 分类约 76 sp；WELCOME 由宽度与透视矩阵拟合。首页机型在独立 70 dp 高区按实际字宽拟合，优先完整呈现；空相机标题在剩余高度内拟合两行，最大 72 sp。尊重系统字号，不通过缩小参数文字强塞六张小卡。

“你的 / 松下相机”采用两行 OPPO Sans：第一行白色，第二行约 60% 白色，左边缘与 Lumix、型号和状态同列，优先遵循图 6 的排版。不将它改成居中单行。“创作记录”大标题与两枚引号采用点阵，正文采用 OPPO Sans。

资产清单见 [字体与资源](assets.md)。Bebas、统圆体与其他 OFL 字体保留原协议；OPPO 采用官方 ZIP 的独立协议，字体保持未修改，并在设置/许可页标明使用。栗壳坚坚体、用户 LUT 和恢复画框图片的来源与公开分发授权记录见[第三方清单](../../THIRD_PARTY_NOTICES.md)；许可说明不插入创作操作流程。

## 5. 空间、对齐与安全区

按 360–430 dp 竖屏布局，不按 PPT 的像素比例直接缩放。

| 项目 | 规格 |
|---|---|
| 统一左右边距 | 20 dp |
| 卡片内边距 | 16–24 dp；首页大卡 24 dp |
| 常规 / 紧凑间距 | 12–16 dp / 6–8 dp |
| 相机、用量、创作卡 | 等宽等高，内宽 × 0.654 + 120 dp × max(字号倍率−1, 0)，限制 218–340 dp，圆角 30 dp |
| 两张快捷卡 | 等宽，与主卡同高，间距 16 dp |
| Film 分类卡 | 高约 190 dp，圆角 26 dp |
| 主按钮 | 高至少 56 dp，圆角 28 dp |
| 圆形入口 | 52 dp，图标约 24 dp |
| 一般触控区域 | 至少 48×48 dp |
| 分类标题触控 | 整行，最小高 56 dp |
| 悬浮底栏 | 高 76 dp，左右 20 dp，安全区底部 16 dp |

同列文本保持左边缘一致；真正的居中区域才居中。播放三角若使用，视觉中心略向右；星星与下载箭头略向上；不靠不一致的左右边距修补。小卡缩略图保持 1:1 裁切；名称与收藏共用下缘排版，超长名称省略，详情完整展示。

主页卡片共用边缘高光、阴影和低透明度细颗粒；这些装饰与流动背景分层，文字不随材质时钟重组。快捷卡上缘分别放蓝牙 / 相册的线形图标圆框及右箭头，下缘有 9 sp 英文辅助文字。相机状态采用真实状态胶囊，不能以装饰性的“已连接”代替协议状态。主页顶栏固定，WELCOME 属于可滚动的主视觉。

edge-to-edge 背景延伸到系统栏；返回、主要按钮与底栏位于 `safeDrawing`。不设置全屏手势排除；系统边缘返回保留。折叠、横屏和大字号布局仍需实际运行确认，不能用桌面比例图代替兼容证据。

## 6. 连接首页

### 相机卡与多机

成功连接后登记相机身份与名称。正常卡显示型号与“已连接 / 未连接”；只有当前会话相机显示已连接。左右滑动和圆点箭头切换卡片，箭头可循环。切换展示不会自动连接另一台，也不改变正在传入的任务。

尚无相机时使用不同颜色的流动高光与明确扩散涟漪，中心写“新增你的松下相机”。正常卡下滑进入新增，上滑进入灰玫瑰删除面；在新增 / 删除面通过返回或反向滑动退出。卡片认领以纵向位移为主、超过约 64 dp 的内部手势，横向留给 pager，外围纵向留给页面滚动。

删除面保留型号、“删除本机”、明确移除与返回。移除需要点击确认，不在滑动结束直接删除。只删除本应用记录，保留照片、历史、创作文字和相机内容；当前连接对应卡被移除时断开会话。个人配置不保存 IP、密码或旧应用身份。

### 用量卡

每屏一个月，按周列 / 星期行展示圆点，左右滑动或箭头切换月份，点击月标题进入每日文字列表。圆点只展示密度，不提供微小触控；每日行高至少 48 dp。

“拍摄 · 已导入”按照片 EXIF 日、稳定 PhotoId 去重；缺失 EXIF 不推算。传入按实际完成时间 `completedAt` 计数，含照片与视频；未完成、失败和暂停不计入。旧记录缺少完成时间时显示未知，不将建立日冒充传入日。统计当前全部已导入记录，不宣称相机全部快门次数或当前一台的完整历史。

密度颜色：0 淡底点，1–4 冷蓝，5–19 明亮冷青，20+ 暖浅黄；每日详情保留准确值和统计口径。相机、用量与创作卡尺寸一致。

### 创作记录

点阵标题；空态提示写下光线、地点和故事；已有正文最多显示三行，点击编辑完整文字。左上、右下点阵引号围绕正文，不压住内容。最多 4000 字符，明确保存 / 取消，保存失败可见，取消不覆盖原文。

## 7. 浏览、选择与后台传输

相机范围仅连接、浏览和传输；浏览初始化可进入播放模式。没有实时取景、快门 / 视频遥控、曝光 / 白平衡 / 焦点、参数复制或远程电源。

相册目录分页、可见缩略图、多选。传入前提供“仅导入手机”“进入 Film 编辑”“进入 LUT 编辑”。照片按批次导入；选择编辑时传入完成后到对应选型。原视频直接保存相册，不进入照片编辑。

仅导入手机不沿用上一批效果和签名；原 JPEG 发布采用字节复制并保留 EXIF / 方向。RAW 只发布所提取内嵌 JPEG，不解码传感器数据。保存继续复用持久导出服务与发布回调。

前台默认显示真实完成数、隐藏与暂停；隐藏后后台服务和通知继续，并可重新显示。断网、系统停止和失败保留队列以供明确继续。未知保存结果先核对；不能无条件自动重试重复保存。

相机 HTTP 固定在用户选择的 Wi-Fi Network 与私有 / 链路本地地址。LUT 与头像请求使用独立 HTTPS 客户端、同源约束和响应上限，不能依赖应用 cleartext 策略保护互联网请求。

## 8. Film 选择与呈现

分类默认单暗盒在右、大衬线文字占据卡片。聚焦分类时标题向左上缩小，暗盒沿共享边界移动进入纵向陈列；其余暗盒渐入，保持空间连续。每类记录上次中心位置，不总是回到第一卷。

同一暗盒图像采用 sharedElement，仅保留一个过渡对象；文字仍可采用 sharedBounds。暗盒姿态随场景过渡连续插值：分类 12°、轮播 −66°、详情 0°，入场和退场均为 420 ms；返回由竖直详情转回原轮播倾角。仅当前关联分类的单暗盒跟随变换，其余卡片保持各自位置。pager 的小数位移由绘制层读取，标签不因每帧偏移重组；邻卷模糊分档缓存，不每帧创建 BlurEffect。这是局部实现与手动观察，未形成完整性能或全目录过渡证据。

轮播约显示三个暗盒，中心清晰明亮、上下暗淡，旋转 / 缩放 / 透明度随离中心距离连续变化。使用惯性与中心吸附；每越过当前项一次轻触觉，不每帧震动。提供名称、序号与显式“查看介绍”。

入场先留出 1000 ms；停止、吸附且入场完成后等待 500 ms 再展开详情。新滚动取消计时。中心暗盒摆正进入详情，外围退出；采用真实目录名称和现有描述，不从参考图片猜 ISO / 工艺字段。

返回详情恢复同分类同中心，关闭自动展开资格；用户再次滚动后才重新允许。减少动态时关闭自动展开，点击查看。详情左上返回、下方“选择此卷”。

点击非中心暗盒先移到中心、保持对应共享边界，再按停稳规则介绍；不能直接开邻卷详情却把返回位置留在旧中心。减少动态时立即移到该项并介绍，不依赖自动计时。

预览控制：曝光 −3…+3 EV，Halation 开关，黑柔 OFF / 1⁄8 / 1⁄4 / 1⁄2；原图对比不写回。批量有逐张独立 / 继承首张，基准身份固定，明确显示名称；切换模式保留独立草稿。

先生成实际效果预览，再呈现显影与渐进反转。负片动画从最终效果图的临时反色连续显现到原效果图，不修改原始像素、不重复反转成片。正片 / 反转片直接显现。视觉动画与真实导出进度独立。

显影约 650 ms，反转 1600 ms，末尾 180 ms。每批首次一次，批次标记持久保存，跳过也计为已播放。跳过进入画框，不取消处理。预览失败显示错误，可跳过或返回；不能宣称动画播完即已保存。

## 9. LUT 分类、双槽与收藏

色彩推荐只提供彩色推荐、自然、暖调与冷调，不提供黑白入口。黑白或几乎没有色彩的原图提示缺少可分析色彩，不用黑白 LUT 凑数。推荐卡片全部使用当前照片的真实试套，未下载官方 LUT 仅临时读取少量候选，实际评估后展示；创作者例图只能初筛，不代替效果图。算法边界与未验证范围见 [修正记录](../engineering/colour-recommendations-20261018.md)。

推荐页的连续背景延伸至系统栏与手势区，内容保留安全边距；默认收起筛选开关，将空间留给约视口 68% 宽的拍立得。按钮背后延续同一背景，避免底部纸色截断。

“我的 LUT”包括内置、本地导入、已下载。Lumix Lab 使用官方社区分类、目录、例图、创作者原介绍与头像；不建设替代服务器，不伪造网络状态。网络失败保留本地流程。

首次 LUT 入口默认展示 Lumix Lab，用户仍可切回“我的 LUT”。官方分类使用服务器 code；服务器提供 title 时采用原值，没有标题的 movie / still 映射为电影 / 摄影。默认为前四个真实类别请求各三张例图元数据，展开才加载完整分页；类别查询缓存最多八组，换语言取消旧查询。分页使用续接 offset，不估计总量。未加载分类可展示文字与引导，不将“全部”页虚分配成风景 / 人像。本地题材由用户在详情标记，未标记仍在全部；不凭标题猜题材。搜索针对已加载名称与创作者，不能宣称全站搜索。

今日推荐由本机从已加载对象按日期轮换，横向卡左方 1:1 图、中间手写名称、右方收藏；不是官方编辑推荐。小拍立得上方 1:1 图，下缘手写名称和收藏。详情从具体被点实例连续放大：纸面、图片、名称同行；下方创作者、头像、原介绍和“选择该 LUT”。

默认每类一行三张；点击标题整行展开，焦点优先两行三张；其他分类收成一行。屏宽小于 340 dp 或系统字号比例超过 1.3 时改为两列 / 两行，优先可读性；其他项目继续可浏览，不静默丢弃。再次点击同标题收起，点击其他标题直接切焦点。超出焦点的卡片仍按三列纵向排列，不再添加横向末行；保留真实分页入口，不能截断后显示为全部。类别布局采用连续尺寸与非线性 easing。

搜索收起时与两枚圆形入口处于同一排，避免闲置的全宽输入框遮住第二排；滚动时隐藏，停止约 700 ms 出现，已有查询保持可见。点开后显示输入框，键盘显示时隐藏主底栏；IME 安全区内保留收起操作。搜索、左下收藏和右下加号均从只包含目录的图层取真实像素，采用 22 dp 模糊、薄底色和细边，不能以灰色透明圆底代替毛玻璃。

两个槽明确标为 LUT 1 → LUT 2，选择详情可指定目标槽；从编辑页更换第二槽进入时指向第二槽，不覆盖第一槽。两槽独立强度、删除和交换顺序；合成后统一颗粒，JPEG 尺寸和质量独立。输入照片风格保留创作者建议。

所有收藏按钮点击一次收藏、再次取消。官方下载前后按 code 同一身份去重。收藏保存 key、名称、创作者和受约束例图引用，重启仍能找回条目。例图无法访问时明确占位，不从无关图片补齐。

收藏从原左下圆形按钮扩张揭示，呈弧形拍立得 pager；滚动过当前项一次轻反馈。点击卡进入普通目录同一详情组件；返回保留页。叉号保持在原星形入口位置，退出后恢复原 LUT 列表位置。取消最后一项出现空态与退出。

收藏按最新参照形成连续弧带：单卡宽度为屏宽 30%，限制 112–154 dp；重叠 16%，旋转约 11° / 项，距离平方 ×10 dp 下移，不突出放大中心卡，中心层级最高。首次打开默认取中间附近，后续按实际页保存。两行明暗衬线标题，上部深蓝留白、右上青光、下方青蓝 / 淡紫漫射采用独立静态 Canvas，避免通用液体材质把深蓝区域提亮。浅色保留冰蓝纸面。

球体区域宽度为屏宽 36%，限制 112–154 dp，使用青色左上、粉紫右上、蓝色下部多个径向色场和外弧 / 小高光；不再在其上重复已在卡片出现的名称。点击进入同一详情，不宣称它是 LUT 色样；拍立得纸色仍取真实 Palette。页数提示使用轻薄胶囊，深色底部漫射变亮时仍保持对比。屏高小于 620 dp 或字号超过 1.3 时，主体可纵向滚动、扇形承载高 280 dp，标题和退出按钮固定；其余视口保留留白与弹性居中。

退出采用与进入相同的 480 ms 圆形收回，圆心对应原按钮（距左 46 dp、距底 162 dp），叉号仍距底 136 dp，叉号承载面取本场景像素做玻璃。圆形裁剪注册在页面可见性过渡中，由同一过渡保留退出图层；收藏图层在列表上方收回。关闭时立即切换保存的页面状态并恢复底栏，不另设延时隐藏底栏；快速反向操作沿当前过渡衔接，减弱动画时直接切换。详情返回保留收藏页位置，不重新播放圆形揭示。收藏列表缩短时，旧页数快照可能暂时请求已经移除的索引；key / 内容读取须容忍此过渡，不让缺失卡片重新出现或导致越界。真实项目保持稳定 key。

小拍立得收藏区域保持 48 dp 触控范围，可见圆底 30 dp，未选 / 已选星形为 17 / 19 dp；推荐与放大态可见圆底 42 dp。选中为金色实心星，取消恢复描边与纸面颜色，点击有回弹；图形大小不以牺牲名称宽度为代价。LUT 标题使用独立固定顶栏，滚动列表占剩余高度，避免浮盖标题向下穿透点击。

小样和主预览均调用恢复后的真实 FrameRenderer；不能以同一边框换颜色代替所有样式。主预览固定 152 dp 承载面、内部 136 dp 图像；点击放大到同配方窗口，可切换批次照片。主操作区为“画框”“文字与细节”“输出”，默认三列纵向画框小样、图像区 1.45:1，边线 / 勾号与 RadioButton 语义表示选中；首屏先露出“选择画框”和小样。签名、参数与压缩不混在同一长表单。整批共享一个配置，但各张保留自身照片、EXIF、方向、取色和片号。旧 EDITORIAL 名称归 PAPER，不算额外预设。

提供纸边、原比例和 1:1 / 3:2 / 4:3 / 7:6 / 5:4 / 15:9 / 2:1，画布跟随照片 / 横向 / 竖向，签名、EXIF 开关、标题 / 副标题 / 页脚、独立字体、装饰图、取色策略，以及暗盒品牌、名称、片尾文字、135 / 120 与彩色 / 黑白标签风格。标签风格不改变照片色彩。预览是最终构图。纸边扩展画布，不静默缩小原图。

细节区采用 22 dp 圆角纸面、16 dp 内边距和 21 sp 中文衬线组标题；签名与信息、构图与纸边、当前预设的配色、暗盒标签分别成组。比例、方向、字体和取色选项自动换行；签名字体名称直接使用成片同一 bundled 字体，按画面实例缓存字体。默认折起更多标题 / 注记，签名字体导入仍直接可见。取色和固定色只在真正使用它们的 PALETTE / FILM 显示，装饰图仅 PALETTE 显示；切换预设不清除原配置。“显示标题与拍摄信息”同时控制标题、副标题和页脚；关闭时额外文本输入禁用并说明原因，签名继续保留。

参数统一项目滑杆：48 dp 触控区、3 dp 轨道、9 dp 手柄、拖动光晕，整数参数按离散档位吸附。横向过触控阈值才接管拖动，竖向拖动留给列表；点击轨道定位。提供读数、范围、setProgress 和方向键操作语义。纸边、曝光、LUT 强度、颗粒、尺寸和质量共同使用此控件，不改变原参数范围。尺寸和质量的初值仍分别为 100% / 95。

预览是合成位图，没有 JPEG / PNG 编码过程；其预览 key 将压缩质量归一为 100，不因单纯调整压缩质量重新计算相同像素。尺寸、配方、画框、导出格式和片号变化仍重新生成所需预览。真正导出使用用户质量、格式和批次快照，此归一仅作用于 UI 缓存，未替换实际输出设置。

默认照片尺寸 100%、JPEG 压缩质量 95，两个控件分别控制；同时显示内容尺寸和最终画布尺寸。「输出」另提供图片格式 JPEG（默认）/ PNG 透明底：PNG 透明底只对「胶片暗盒」「记忆票根」生效，其他画框保留自身底色；PNG 不写 EXIF，也不使用 JPEG 压缩质量。RAW 提示只说明内嵌图尺寸，不进入水印。默认相册 `Pictures/LumixFilmMirror`，可选择文件夹。

确认导出固定配方、各张种子、画框、输出和目标快照，后台执行不受后续草稿变动影响。成功、失败、需核对分开显示，重试只针对确定失败。水印独立导入为原图；Film / LUT 导出保留效果。

原图、无框、100% 尺寸与质量 100 的特定发布路径直接复制 JPEG；其余正常处理与编码。仅导入手机显式使用此路径，避免再次压缩。该字节复制路径只适用于 JPEG；PNG 输出始终正常解码、渲染与编码。

## 11. 动态、触觉与模糊

| 动作 | 时间 / 模型 | 约束 |
|---|---|---|
| 共享边界 / 页面退出 | 通常 420 / 280 ms，Film 两端 420 ms | 具体卡片实例 key 唯一；同暗盒单一图像对象 |
| 贝塞尔 | (.22,.8,.22,1) | 迅速进入，缓慢停稳 |
| Film 惯性 | pager fling / 吸附 | 停稳再计时 |
| 自动详情 | 停稳 500 ms，入场 1000 ms | 返回禁止，直至用户新拖动 |
| LUT 分类 | 420 ms | 连续尺寸变化 |
| 收藏圆形揭示 | 480 ms | 从原星形圆心扩张 |
| 空相机涟漪 | 三波扩散，约 8.1 s 自然波周期 | 颜色场没有循环重播端点；减少动态停止 |
| 搜索重现 | 停止 700 ms | 已有文字不隐藏 |
| 显影呈现 | 650 / 1600 / 180 ms | 每批一次，跳过可用 |
| 触觉 | 越过当前项一次 | 尊重系统，不持续振动 |

系统动画比例 0 或用户开启减少动态：关闭自动详情、持续涟漪与渐进模糊；其余过渡尽量直接完成；全部功能仍可点击访问。无需通过手势才能完成删除或返回。

底部 128 dp 使用真实页面内容的捕获层，六档 2 / 5 / 10 / 18 / 28 / 40 dp 模糊结合纵向 alpha 蒙版渐进混合；底栏另采集真实画面做 22 dp 毛玻璃，控制内容保持锐利可点击。透明 tint 只补材质，不能冒充背景模糊。只在主导航可见时开启；详情、编辑、显影和导出不运行底栏模糊。实际帧率、内存和 GPU / API 30 兼容仍需运行证据。

## 12. 持久化、错误与可访问性

批次、配方、画框与队列继续用现有 Room；完成时间通过非破坏的 8→9 增量迁移追加。相机名称、收藏、创作文字和显影已播标记使用本应用独立个人配置。没有清库或导入旧应用数据库、签名和身份。

编辑照片只展示本次会话批次；退出任务或进程重新启动后不恢复上一批照片与编辑页面。正在执行的后台传输 / 导出可以保留任务批次；旋转和系统相册选择不结束会话。收藏、创作记录、相机和用量不受影响。历史内部副本不自动展示，不对原图与已发布成片做清理。

主要动作均有文字 / 可访问性名称；收藏与 tab 有选中语义；胶卷有名称和序号。圆点仅是视觉风格。密集用量点提供读数语义，具体日期操作放 48dp 每日列表。

导入、目录、例图、下载、预览、编码与发布分别处理错误；单张失败保留其他已保存结果。未加载图片不能标为已应用。个人配置读取失败保留原记录并提示，不重写空配置覆盖损坏文件。取消与返回不触发清理原片。

源码与恢复资料、生成审阅文件分目录管理；所有原件保留。打包和交付附属记录放 `dist`。规范、源码编译、APK、设备、照片效果和性能是不同证据等级；本轮未运行测试。
