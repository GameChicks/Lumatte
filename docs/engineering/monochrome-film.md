# 自有黑白胶片功能（2026-10-11）

固定 spektrafilm 来源的 20 款资源没有提供黑白模型。本轮加入两项本项目自有风格：`lfm_silver_neutral`（Silver · Neutral，中性）和 `lfm_silver_contrast`（Silver · Contrast，高反差）。它们是艺术参数的银盐负片／相纸近似，**没有品牌胶卷实测标定**，不以 HP5、Tri-X 等商品名称呈现，也不称作 spektrafilm 的黑白数据。

实际运行了本项目 `tools/produce_monochrome_models.py`，生产两项数据包与轻量目录。原件和彩色来源资源没有改写。Android 目录、模型读取、GLES／CPU 共用入口有源码接线；没有编译、运行照片、设备验证、测试、基准或 APK。

## 三阶段与曝光

1. 编码 sRGB 先线性化，以 `.2126/.7152/.0722` 亮度权重产生单一响应。这是自有全色亮度近似，不是测得的银盐光谱敏感度。该响应复制到三通道，以复用既有传输格式。
2. 运行时在响应域加入黑白中性 Halation，统一 EV 增益只乘一次。log10 曝光通过有趾部、肩部的 sigmoid 显影曲线转成银盐密度。中性／高反差预设的曲线斜率分别为 1.8／2.2，底密度 .08、密度幅度 2.2，参考线性灰 .184；三个通道保持同一密度意义，没有彩色 DIR 或 CMY 染料耦合。
3. 密度颗粒之后，扫描阶段取三通道平均银盐密度，负片透光的 `log10(T) = -D` 进入固定相纸 sigmoid。由相纸密度求反射亮度 `10^-Dpaper`，以固定黑／白参考归一化并编码 sRGB，三个输出通道相同。不再在导出末端做一次反相。

相纸底密度 .015、密度幅度 2.7、斜率 3；生产时求固定曝光，使参考灰在固定扫描归一化后落到 .184。这是解析生成函数的参数选择，资源的离散采样和插值仍可能偏离，并非实际照片对照结果。不会按每张图重算相纸曝光，因此首张参数继承、逐张 EV 和预览／导出使用同一处理规则。

response／development／scan 仍为 33³／33³／41³ 的 float32 三阶段表。容器沿用 `film_cmy_density` 阶段标签，但本来源三个通道承载的是同一银盐密度，manifest 的 `none_silver_density` 标识对此作出区分，没有 CMY 染料假设。显影 log 域为 −6～2，扫描域为 −.2～2.48；超域沿用端点夹取。每卷 1,689,540 数值表字节，两卷 3,379,080 字节，另有 JSON 和许可；不是 APK 体积或总内存上限。表尺寸、曲线和扫描参考尚未通过照片或误差核对。

## 空间效果、颗粒与批量

共享既有镜头线性 RGB 黑柔，提供关闭／1/8／1/4／1/2。Halation 的三通道参考强度同为 .06、半径参考 60 μm，运行时共用艺术可见性映射，因此银盐域为中性光晕。颜色来源仍来自亮度响应，最终扫描保持中性。

颗粒复用移动密度方差和相关噪声近似，粒子面积 .45 μm²、uniformity .9、颗粒底 .02；中性／高反差粒子比例分别为 1／1.4。三通道噪声最终取平均密度后印相，不能将这组艺术参数称作真实银盐粒径分布或与彩色源模型完全等价。各张保留自己的种子，批量继承仅共享配方，画框仍在导出阶段整批共享。

## 目录、来源和前端

独立资产放 `film/mobile-monochrome-v1/`，不把自有条目写入彩色 spektrafilm 目录，也不更改彩色生产脚本。来源版本 `lfm-silver-three-stage-v1`，GPL-3.0-only 随本项目许可；LICENSE 原文按原字节复制，NOTICE 与 manifest 保存来源、参数和未标定状态。

`FilmCatalogue.load()` 合并彩色和自有黑白的轻量目录；`FilmPreset.description` 给出自有来源说明，选型详情可直接显示。`MobileFilmModelInfo.origin` 为 `SPEKTRAFILM` 或 `PROJECT_MONOCHROME`；后者 `sourceCommit=null`，不伪造上游 Git 提交。前端按 origin 显示来源，不能对可空提交字段直接截取字符串。

模型读取器按 Entry 所属根目录与固定版本验证 manifest／各表哈希，缓存仍为所有类别合计两卷／4 MiB。黑白使用同一 PhotoProcessor、GLES／CPU、逐张／首张继承和整批导出，无新增界面或 Room 迁移。实际效果、灰阶、曝光响应、夜景光晕和手机执行仍待授权范围内的后续实际验证。
