# 松映 · Pineframe：材质、收藏和桌面小组件

用户确认新名为「松映 · Pineframe」。松字呼应松下适配用途，Pine 与 frame 组合表达胶片及画框；保持独立第三方身份。应用名称、主页、设置和前台任务通知同步更名，应用 ID、数据文件及已有相机记录保持连续。

## 本轮界面

- 收藏拍立得默认宽度从视口 50% 提升至 66%，上限 330 dp，并受可用高度约束；短屏幕允许滚动。仍可看到左右两侧的收藏卡片。
- 浅色采用暖纸底，Film 选型背景的类别色点缀加深；收藏背景增加海蓝色层次。暗色的全局纸面、边线、文字与背景改为炭黑 / 深蓝 / 琥珀，移除原有黑绿主色组合。
- 主页相机用量仅为当月展示卡片，移除月份选择、指标按钮、每日明细与弹窗。7 列 / 6 行点阵由同一个 Canvas 按可用格子尺寸绘制，每格仅有一个圆点。拍摄计数仍来自已导入照片的日期；传入计数来自已完成任务。
- 删除 Film 分类卡片的“日常 · 自然 · 温暖”等第二层小字。配对页保留操作提示及失败时必要的权限指引，移除常驻权限原理和广播数量报告。

## 桌面小组件

采用 Android 原生 AppWidgetProvider / RemoteViews，无新依赖，无周期刷新、相机轮询或后台连接。实现参考 [Android 官方配置文档](https://developer.android.com/develop/ui/views/appwidgets/configuration)。

提供柔光胶卷、分层胶卷、相机连接三个可调整大小的组件。视觉按用户给出的三张参考图独立绘制，背景为代码生成的圆角渐变，不将参考图片直接用于界面。

- 每个实例独立保存胶卷 / 已记住的机型、显示名称、背景颜色。提供海蓝、日落、陶粉、苔金、鸢尾、赤陶六种预设，也可输入六位 HEX 自定义颜色。
- 胶卷组件点击打开选定胶卷的导入选择，导入新批次后沿用该胶片进入编辑，不改写已存在批次。推片项仍绑定具体配方 ID。
- 相机组件点击进入连接页，并带入所选已记住的相机；没有自动进行连接、扫描或远程控制。组件不显示伪造快门、曝光或电量数据。
- 初次添加有配置页；系统支持时长按重配，应用“设置 → 关于 → 桌面小组件”也提供已添加组件的编辑入口及请求固定到桌面的入口。
- 冷启动等待工作台恢复完成，运行中先等待现有任务结束。取消导入后不会自动再次弹出；Activity 重建避免重复消费已处理入口。组件 ID 与目标均从应用自己的配置读取，目标胶卷再由当前目录校验。
- 使用独立 PendingIntent 标识每个组件；删除组件清除其配置，恢复时迁移 ID。系统尺寸变化时重新绘制，背景位图长边限制 512 px；字号由原生 TextView 按空间缩放。

## 主页后续可选卡片

建议优先考虑：继续上次编辑（显示剩余照片并进入原批次）、一卷日签（每天一卷已内置胶片）、最近导出（三张预览，回看成片）。这些是建议，本轮未增加新的主页入口。
