已有 Wi-Fi 的多个网络选择已接入普通查找、STA 普通／发送／更新和断线后普通重连；列表可刷新／取消，发现及 HTTP 绑定所选网络。同网络的应用请求保留，避免关闭请求导致所选网络消失，详见 [已有网络选择](wifi-network-selection.md)。手动直连另增加 WPA2／WPA3-SAE／开放选项、按类型的密码验证及手机 SAE 能力检查，蓝牙仍保持原有开放／WPA2 行为，见 [安全类型](wifi-security.md)。源码接入不等于并行 Wi-Fi、网络可见性、安全类型或生命周期已以设备验证。

参考 APK 的成功使用反馈、JADX 输出、资源清单与源码审阅不等于本应用已兼容所有相机。阶段 2 仍未完成；按用户最新要求，遗留适配项保留记录，现在优先进行第三阶段影像编辑。

普通相机浏览已接入按可见项加载的目录缩略图：只请求 CAM_LRGTN／CAM_TN、串行下载、4 MiB 响应上限、384 像素采样、8 MiB 位图缓存；目录刷新与会话切换隔离缓存，其他操作／传输／页面离开时取消自身请求。缺少预览保留占位，不改变所选原文件。待发送模式不加载预览，详见 [相机缩略图](camera-thumbnails.md)。以上仅为源码接入，未编译或验证。

缩略图进一步接入自身 EXIF 的八种旋转／镜像方向，与本地预览／JPEG 导出共用方向映射；大缩略图失败时尝试目录声明的小缩略图，取消不启动备用请求。小图上限只用于相机浏览，默认 100% 导出仍沿用有效输入尺寸。真实机型方向标签、资源失败及取消时序尚未验证。

工作台新增持久处理批次、新建／切换入口、本地导入预登记归属和相机队列归组；预览与导出不再直接使用全部历史照片。Room 4 提供 3 → 4 的新增表迁移，详见 [处理批次](processing-batches.md)。其后 Room 6 新增逐张胶片配方和首张继承持久化，共享画框绘制仍待接入；全部迁移与导出范围尚未运行验证。

目录资源进一步接入官方 Sync 解析中的三段式 protocolInfo 兼容分支，统一 JPEG／RAW／HSP／缩略图及视频标识的大小写比较，并保留带引号名称中的分号／等号。详见 [资源标识](camera-resource-profiles.md)。没有执行解析样例或机型测试，未知资源仍不推断为原图。

视频目录识别进一步接入 UPnP 视频类／派生类及不依赖 CAM_AVC 前缀的独立 IFRAME 标识。只提供封面或预览的视频项目不进入照片导入；普通列表提示缺少完整资源，待发送首项暂停且不确认保存。已支持 MP4／MOV／TS 的原文件路径保持。详见 [视频项目与封面](camera-resource-profiles.md#视频项目与封面)；只做源码审阅，没有执行样例、测试或设备传输。

相机局域网 IPv6 源码接入 ULA／链路本地地址、所选 Wi-Fi 的作用域验证、并行 IPv4／IPv6 SSDP、数值地址一致性检查及 IPv6 HTTP 适配器；网络选择列表同时显示 IPv4／IPv6 本机地址。IPv4 保留系统传输，蓝牙发送地址字段仍限定 IPv4。详见 [IPv6 路径](camera-ipv6.md)。没有执行发现、请求、取消、下载或样例；真实机型 IPv6 兼容性仍待验证，阶段 2 不因此标记完成。

默认发布目录 `Pictures/LumixFilmMirror`，可选择其他目标文件夹。当前 exporter 尚不绘制画框；框架布局基础不能作为画框已实现的证据。RAW 说明仅出现在界面，使用实际提取尺寸。

2026-10-11 优先影像编辑：已接入共享 CPU 双 LUT 管线，槽 1 → 槽 2 各自强度、交换顺序、颗粒、照片卡片／全屏选择、原图对比及整批导出；Room 5 声明 4 → 5 新增表保存批次 LUT 配方。本地 .cube 导入、原子缓存和用户提供 10 款内置 LUT 已接入。千禧回声 cold／warm 的内容哈希相同，两名称保留并记录。见 [LUT 管线](lut-pipeline.md)、[内置资产](bundled-luts.md)。仅静态源码审阅和资产记录，未执行解析、渲染、迁移、编译或测试。

随后接入固定 SpektraLab C++／Vulkan 光谱源码、资源、JNI、20 个胶卷显示目录和 PhotoProcessor；提供统一曝光、Halation、三档黑柔、逐张／首张继承草稿、原图比较和真实导出阶段。Room 6 声明 5 → 6 新表迁移。小预览、大图分带、输入转换查表和原生取消适配为初步优化，不证明手机全分辨率速度或内存达标。没有编译、渲染、GPU 请求或测试，见 [胶片接入](film-engine.md)。按最新要求，UI 留给另一个前端，相关新界面撤回，仅保留既有 LUT 原型和 [接口交接](frontend-contract.md)。

RAW 原生补充路径与工具链声明见 [RAW 预览记录](raw-preview.md)。源码及上游文件已接入，NDK／CMake 未运行，不能作为 JPEG 提取、性能或 16 KiB 安装兼容的证明。

蓝牙入口已加入最小工作台，读取的密码仅临时用于系统 Wi-Fi 请求，未写入持久化状态；详见 [蓝牙连接资料](bluetooth-connection.md)。普通 SoftAP 传输启动已接入固定值指令和两种连接通知；发送入口额外订阅图片／模式通知，收到相机请求后写对应固定模式 1／6，核对 HTTP 模式后才初始化发送目录。模式变化和已知模式的资料更新会生成显式更新入口，重新读取资料并按原 UDN 核对。普通 STA 入口先发送路由器名称、等待选择确认，再写类型 2／普通模式 3，绑定已有 Wi-Fi 发现和浏览。STA 发送入口先等相机模式，再写路由器名称、类型 2 和对应模式 1／6，后续接收及更新保留该路径。三个入口现在统一接入完整 UTF-8／32 字节名称验证、参考字符补零及按载荷长度检查实际 MTU，界面增加字节计数，见 [同路由器连接](router-wifi.md)。保留手动开启入口；更多通知、STA 交接、非 UTF-8 名称与逐机型编码差异仍需继续，尚未以任何真实相机验证，不能据此判定第二阶段完成。

相机视频直接保存到 `Movies/LumixFilmMirror`，不进入照片工作台，不转码或套效果；队列明细可以打开已保存视频。已识别容器不等于每个机型能传输，也不等于手机能播放所有视频编码。

发送连接及发送更新已接入就绪状态后的可读相机地址：当前 GATT 收到状态 0 后读取发送服务的地址特征，合法私有／链路本地 IPv4 用于所选 Wi-Fi 上的定点设备描述发现。缺少能力／就绪时仍可走 SSDP；有效地址不响应或原 UDN 不符时不改用其他相机。普通浏览仍保留 SSDP，逐型号通知时序和其他地址格式尚未验证，见 [连接地址](camera-connection-address.md)。
