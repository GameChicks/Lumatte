Lumix Film Mirror: sf-3bb2c2d-print-presets-v2
Source: spektrafilm 3bb2c2d2801ff68b92019cf1dbcbb133d60832bc, Andrea Volpato.
Derived data licensed CC BY-SA 4.0. Generated float32, x-fastest, per-stock tables.
sRGB -> linear film response (33^3), log exposure -> density/local DIR (33^3),
density -> fixed paper/positive scan sRGB (41^3). Exposure is zero at bake.
Spatial effects, random grain and automatic exposure are disabled during bake.
DIR spatial diffusion is omitted; local chemistry is baked once.
Project print presets: stock-specific receivers, restrained print gamma and a fixed neutral-reference printer balance; reversal stocks remain direct scans.
Vision3 250D curve correction: Fotufilm / MUAStudio Inc., CC BY-SA 4.0, commit 079844387659045a39ef4e5005191b0d77b81606. Spectral-basis projection is a mobile approximation.
Sampling and float32 encoding are modifications. No accuracy/performance validation was run.
