## 当前设计

水印固定衬线大标题；152 dp 构图承载面内显示 136 dp 实际预览，可点按“放大”进入同配方的大图。放大窗口可切换批次照片，复用实际预览缓存，不另外加工或保存。操作区分为画框、文字与细节、输出；11 款真实 FrameRenderer 小样改为三列纵向排列，缩略图区比例 1.45:1，保留原照片构图、选中边线和勾号、RadioButton 选中语义。默认首屏更早看到画框，不再把签名、比例、字体、文件夹和压缩控件混在一个长表单中。文字 / EXIF / 120 暗盒开关改为项目输入和开关；原参数、图像、字体选择器、保存快照不变。

LUT 搜索收起时与收藏、导入处于同一排，点开才显示单行输入，滚动隐藏、停稳重现的节奏继续保留。三枚悬浮控件从“仅包含目录的捕获层”采集背后真实像素，使用原 22 dp 玻璃管线和约 40% 材质底色，文字保持锐利。嵌套控件按 root 坐标减去源层原点，避免把父容器坐标误当作页面坐标；捕获层不含控件本身，不回采上一帧玻璃。键盘打开时隐藏主底栏，避免它跟随安全区上移盖住输入。

收藏参照 Screenshot_20261011_064142：两行明暗标题、深蓝场景与底部浅蓝漫射、连续弧带以及彩色球体。卡宽屏幕 30%（112–154 dp），重叠 16%，中心和邻卡不再明显缩放；位移为距离平方 ×10 dp，转角 11°、横向透视 −10° / 项。纸面取实际 Palette 中较鲜明的颜色并混合 24% 暖纸色，重新选择对比墨色；目录普通拍立得继续原取色。球体是参考所示的装饰光学材质，青 / 淡蓝 / 淡紫 / 蓝渐变、弧线与小高光，不将它宣称为 LUT 色样。叉号位置和圆形揭示 / 收回保持原逻辑，退出按钮也采集本场景像素做玻璃。

Film 轮播补齐大衬线分类标题与左侧连续刻度；中心胶卷明亮、邻卷暗淡的逻辑保留。新增 C200 imagegen 暗盒，与 Gold 200 的几何、照明相配；其余还存在恢复标签套筒，不能宣称全目录材质已经统一。发现点击非中心暗盒会直接跳详情、返回仍到旧中心；改为先吸附被点暗盒、再按停稳规则展开，使共享边界和返回位置属于同一卷。手动从 Gold 点击下方 C200，打开 C200 详情，返回后序号 02 的 C200 保持中心。仍需要继续核对分类到聚焦 / 详情的连续空间变化，而不是仅修改字号和背景。

主页创作、偏好、删除、用量、日期，以及 LUT 添加和照片来源菜单使用项目纸面窗口、按钮、输入和开关。窗口采用 Dialog 的平台焦点 / IME 机制，内部外观由项目绘制；safeDrawing 和 IME 保持可用，高度不超过可用区域，内容可纵向滚动。关闭状态跨重建保存，关闭有 180 ms 退场。日期选择等到旧窗口退出后再开新窗口，避免叠加两个窗口。
